# Browser Testbench 0.7.3

This patch fixes video downloads when a local Browser Testbench is connected to a remote host. Recording still runs on the remote computer, where OBS and FFmpeg must be installed. When recording stops, the video now streams through the local gateway and is saved at the path requested by the controlling client. The client checks its size and SHA-256 digest before accepting it.

The remote browser must be able to reach the website through a network address; `localhost` on the controlling computer is not reachable from the remote host. Update both Testbench installations to 0.7.3 before reconnecting. No recording API or project changes are required.
