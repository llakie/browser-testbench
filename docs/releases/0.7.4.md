# Browser Testbench 0.7.4

This patch hardens OBS startup. After the WebSocket handshake, Browser Testbench waits until OBS accepts a version request before it opens recording sessions or sends further commands. This avoids transient failures when OBS is connected but has not finished initializing its request service.

There are no API, project-format, or recording-format changes. Update the Testbench installation used by Director and remote hosts to 0.7.4.
