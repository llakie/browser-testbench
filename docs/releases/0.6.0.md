# Browser Testbench 0.6.0

Version 0.6.0 adds explicit viewport recording for desktop Chrome, Edge, and Firefox sessions.

## Desktop viewport recording

Desktop browser sessions now advertise viewport recording when `ffmpeg` and `ffprobe` are available. The existing
recording lifecycle captures the active browser viewport and produces an MP4 with stable frame timing. Mobile targets
continue to use their native recording backend.

Recording remains explicit: clients start and stop it through the existing recording API. Screenshot features do not
require FFmpeg and remain available when the media tools are missing.

## Requirements

Install `ffmpeg` and `ffprobe` on `PATH` before starting Browser Testbench when video recording is required. The
Overview page reports whether both tools are available and provides platform-specific installation guidance.

## Compatibility

There are no source-level API or configuration changes. Clients and servers must continue to use the same Browser
Testbench version.
