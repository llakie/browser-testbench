# Browser Testbench 0.7.2

This patch fixes session cleanup after an Android Chrome renderer crash. Cleanup no longer depends on a browser geometry query before stopping an active recording. If Chrome then reports that the tab crashed, Testbench releases the target after Appium has stopped successfully. This does not prevent Chrome itself from crashing under device or emulator memory pressure.

The transitive Axios version used by Appium is pinned to a patched release. There are no API or recording-format changes. Update clients and the server together to 0.7.2.
