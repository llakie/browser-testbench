# Browser Testbench 0.7.5

This patch makes structured desktop viewport screenshots consistent across the supported browsers. Safari now captures the page rather than its rounded native window frame. Firefox screenshots remain visually unchanged while their transparent edge pixels become opaque, preventing unwanted black or transparent output during format conversion.

There are no API, project-format, or recording-format changes. Update the Testbench installation used by Director and remote hosts to 0.7.5.
