# Browser Testbench 0.7.1

This patch corrects the time origin returned by the recording clock and used for timeline marks.

OBS reports output duration from frames that have already passed through its encoder. Using that value as the
capture clock included encoder latency, which could shift downstream cuts by about a second even though the
recorded picture and sound were synchronized.

Testbench now anchors the clock to OBS's recording-start event. It still waits for active output and written media
before reporting the recorder ready. There are no API changes, new settings, or changes to per-device audio offsets.

Update clients and the server together to 0.7.1. Existing OBS setup and recording settings remain valid.
